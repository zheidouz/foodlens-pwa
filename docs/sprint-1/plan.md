## 🧩 Task Breakdown

### 1.1 — Scaffold Next.js App

**Command**:
```bash
npx create-next-app@latest . --typescript --tailwind --eslint --app --src-dir --import-alias "@/*"
```

**Key files created**:
- `src/app/page.tsx` — Home page (placeholder: "FoodLens — Tap to Scan")

- `tailwind.config.ts` — Custom theme colors (primary: emerald-500, secondary: sky-500)
- `tsconfig.json` — Path aliases configured

**Acceptance**: `npm run dev` starts the app, browser shows the placeholder page.

---

### 1.2 — Configure PWA

**Dependencies**:
```bash
npm install @serwist/next @serwist/sw
```

**Files to create/modify**:
- `public/manifest.json` — App name "FoodLens", theme color `#10b981`, icons (192/512/maskable)
- `public/sw.js` — Service worker with:
  - Cache-first strategy for static assets
  - Network-first for scan results (cache fallback)
  - Stale-while-revalidate for UI shell
- `public/offline.html` — Offline fallback page with "Connect to the internet to scan" message
- `src/app/layout.tsx` — Add `<link rel="manifest">` and meta theme-color tags

**Acceptance**: Lighthouse PWA checklist passes — installable, works offline, has manifest.

### 1.3 — Firebase Project Setup

**Steps**:
1. Go to [Firebase Console](https://console.firebase.google.com) → Create project "food-scanner-app"
2. Enable **Authentication** → Sign-in methods: Anonymous
3. Enable **Cloud Firestore** → Native mode, location: `us-central1`
4. Enable **Cloud Functions** → billing required (Blaze plan)
5. Enable **Firebase Hosting**

**Config files** (generated by `firebase init`):
- `firebase.json` — Hosting config (public/, rewrites to `/index.html` for SPA)
- `.firebaserc` — Project alias
- `firestore.rules` — Start locked, will refine in Sprint 3
- `firestore.indexes.json` — Empty, will add as needed

**Command**:
```bash
firebase login
firebase init hosting
```

**Acceptance**: `firebase deploy --only hosting` succeeds and serves a blank page.

### 1.4 — Initialize Firebase SDK

**File**: `src/lib/firebase.ts`

```typescript
import { initializeApp } from "firebase/app";
import { getAuth, signInAnonymously, onAuthStateChanged } from "firebase/auth";
import { getFirestore } from "firebase/firestore";
import { getStorage } from "firebase/storage";
import { getAnalytics } from "firebase/analytics";

const firebaseConfig = {
  apiKey: process.env.NEXT_PUBLIC_FIREBASE_API_KEY,
  authDomain: process.env.NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN,
  projectId: process.env.NEXT_PUBLIC_FIREBASE_PROJECT_ID,
  storageBucket: process.env.NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET,
  messagingSenderId: process.env.NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID,
  appId: process.env.NEXT_PUBLIC_FIREBASE_APP_ID,
  measurementId: process.env.NEXT_PUBLIC_FIREBASE_MEASUREMENT_ID,
};

const app = initializeApp(firebaseConfig);
export const auth = getAuth(app);
export const db = getFirestore(app);
export const storage = getStorage(app);
export const analytics = typeof window !== "undefined" ? getAnalytics(app) : null;

// Auto-sign-in anonymously on load
export function initAuth() {
  onAuthStateChanged(auth, (user) => {
    if (!user) {
      signInAnonymously(auth).catch(console.error);
    }
  });
}
```

**Env file**: `.env.local` with Firebase config values (gitignored).

**Acceptance**: App connects to Firebase — anonymous auth completes silently on page load.

### 1.5 — Deploy to Firebase Hosting

**Steps**:
1. Build: `npm run build`
2. Preview: `firebase serve` (localhost:5000)
3. Deploy: `firebase deploy --only hosting`

**Verification**:
- Visit `https://food-scanner-app.web.app`
- Confirm manifest loads (DevTools → Application → Manifest)
- Confirm service worker registers (DevTools → Application → Service Workers)
- Toggle offline in DevTools → confirm offline page shows

**Acceptance**: Public URL serves the PWA with working service worker and offline fallback.
