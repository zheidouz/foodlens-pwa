## Architecture Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| PWA Library | `@serwist/next` (webpack) | Most stable, Turbopack support is experimental |
| Build Mode | Static export (`output: 'export'`) | Required for Firebase Hosting compatibility |
| Auth Pattern | Client component (`AuthInitializer`) | Keeps root layout as server component for metadata |
| Theme Colors | Emerald-500 primary, Sky-500 secondary | Matches FoodLens branding, accessible contrast |
| Icons | Generated PNGs via Node.js script | Avoids dependency on image editing tools |
